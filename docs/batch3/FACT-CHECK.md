**The ranking itself is unverified.** Live market data could not be reached from the build environment, so the 30 coins and their order are a snapshot from the builder’s own knowledge, filtered by your rules. Fix the list in `thehybit-coins/config/coins-batch3.php` → `$active`: one line per coin.

## CoinGecko ids and identifiers to confirm

- `aster-2` (Aster): the id I was least sure of. If it is wrong, the page shows no price data until it is corrected.
- Contract addresses used for DEX data: WLFI `0xdA5e1988…BeF6`, BGB not set (unsure), ASTER not set (unsure), TRUMP (Solana) `6p6xgHyF…GiPN`. A wrong address only makes the DEX row disappear; it can never show another coin’s data (pairs are also filtered by symbol).
- DefiLlama chain names: Mantle, Cronos, Near, ICP, EthereumClassic, Aptos, Algorand, CosmosHub, Arbitrum, VeChain, Polygon, Filecoin. Not set (unsure whether DefiLlama tracks the chain): Polkadot, Bittensor, Kaspa, X Layer (OKB).
- Kraken pairs that may not exist: KAS/USD, MNT/USD, WLFI/USD, TAO/USD, ONDO/USD, ENA/USD. A pair Kraken does not list is rejected and the coin stays on polling.
