# 2.5.0 — fact-check list for the editor

Correct a line in the coin’s «داستان» / «رویدادهای قیمت» field in wp-admin, or delete it. An edited field is never overwritten by a later update.

Also check:

- **Figures inside explanations** (amounts and percentages), e.g. Binance’s ~$4.3B settlement, Ripple’s ~$125M penalty, the Cetus hack (~$200M), XRP’s +70% day, SHIB’s rise.
- **“اوج” (peak) dates.** The chart pins each event to the price on that day, so a wrong peak date shows a marker slightly off the top.
- **Roadmap items** for Ethereum (Glamsterdam, Hegotá, Lean Ethereum) and Solana (Alpenglow). These move with every core-developer decision.
